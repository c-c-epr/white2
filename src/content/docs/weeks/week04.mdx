## MQTT

訊息佇列遙測傳輸（Message Queuing Telemetry Transport）是一種輕量級的通訊協定，
主要用於物聯網（IoT）設備之間的通訊。

發布者（Publisher）把訊息送到某個主題（Topic），訂閱者（Subscriber）訂閱主題後收到訊息。
中間通常有一個稱為 Broker（訊息代理伺服器） 的角色。

## Pico 2W 連接網路

### 手機熱點

:::caution
Pico 2W 內建的 WiFi 僅支援 2.4GHz 頻段，若使用 5GHz 頻段的 WiFi 熱點，Pico 2W 將無法連線。  
故 iOS 裝置開啟個人熱點時，請務必將「最大相容性」選項打開，否則 Pico 2W 將無法連線。
:::

### 發送消息到 MQTT

安裝以下兩個檔案

<FileTree>

- umqtt
  - [simple.py](/codes/MQTT.py) 輔助函式庫，提供 MQTT 連線、訂閱、發布等功能（**必裝**）
- [content-mqtt.py](/codes/content-mqtt.py) 主要程式（**必裝**）

</FileTree>

需修改網路名稱與密碼、MQTT 設定，然後將檔案安裝到 Pico 2W。

```python /".{1,}"/
//content-mqtt.py
...
# Network Initialization
ssid = "Pixel4"
password = "123456789"
...
# MQTT Configuration
mqtt_host = "broker.mqttgo.io"  # Fixed case sensitivity
mqtt_username = ""  # Your MQTTGO.io username
mqtt_password = ""  # MQTTGO.io key
mqtt_publish_topic = "yisong/temp"  # The MQTT topic for your feed溫度
mqtt_publish_topic2 = "yisong/hum"  # 濕度
mqtt_client_id = "somethingreallyrandomandunique123"
...
```
